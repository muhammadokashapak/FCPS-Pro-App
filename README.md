## 📌 Overview
**FCPS Pro App** is a cross-platform medical postgraduate exam preparation application engineered for doctors and candidates preparing for **FCPS Part 1 & Part 2** examinations. It delivers interactive practice modules, timed exam simulations, verified answer keys, and detailed clinical explanations.

---

## ✨ Key Features
- 📚 **Comprehensive Question Bank:** Categorized MCQs across Anatomy, Physiology, Pathology, Pharmacology, and Surgery/Medicine disciplines.
- ⏱️ **Exam Simulation Mode:** Realistic countdown timer and real-time score tabulation.
- 🎉 **Gamified Feedback:** Interactive visual feedback and completion celebrations with canvas-confetti.
- 📱 **Multi-Platform Deployment:** Runs natively on Android via Capacitor and on Windows Desktop via Inno Setup and PyInstaller wrapper.

---

## 🛠️ Tech Stack
- **Frontend Framework:** React 18 (Hooks, Modern State Architecture)
- **Build Tool:** Vite 5
- **Icons & UI:** Lucide React, Modern Responsive Design
- **Mobile Engine:** Capacitor Core & Android CLI
- **Desktop Packaging:** PyInstaller (`FCPS_Pro_App.spec`) + Inno Setup Script (`fcps_pro_installer.iss`)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Sync with Android Project
```bash
npx cap sync android
npx cap open android
```
